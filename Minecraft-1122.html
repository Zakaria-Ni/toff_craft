Cloaking & Undetectable
Instantly disguises this launcher tab AND the launched game tab (title + favicon). Presets are static data-URI icons — no animation loops, no runtime drawing, zero measurable performance cost. Default: Google Docs.
Favicon Cloaking
Switches the launched tab's favicon to a generic school/work icon (static data-URI icons, no external fetches).
Defeats monitoring software that fingerprints tabs by exact favicon byte hash.
Eaglercraft occasionally resets the tab's favicon to its default. This re-injects your chosen icon on a 2-second interval.
Some monitoring software inspects data: URLs but not blob: URLs. Wraps the icon in a blob: URL for extra stealth.
Title & Referrer Cloaking
When enabled, the launched game tab cycles through plausible school/work titles every 5s. Append |preset (e.g. Google Classroom|calendar) to swap the favicon to match each title.
When on, cycled titles without a |preset suffix will be auto-paired: “Google Classroom” → Classroom icon, “Google Docs - Untitled document” → Docs icon, “Gmail - Inbox” → Gmail icon, etc. Uses a 6-preset educational icon library (static data: URIs, no external fetches).
Prevents the launched tab from leaking its origin via the Referer HTTP header, and nulls window.opener so monitoring software can't trace back to this launcher.
Audio & Panic Cloaking
Workaround for the missing chrome.tabs.mute API. Suspends the game's Web Audio when the tab loses focus so teachers can't hear it from across the room.
When on, the panic key must be pressed twice within 500ms to actually trigger. Prevents accidental triggers during gameplay.
Defends against teacher peeking. If the launched tab loses focus for more than 3 seconds, panic fires automatically — closing the tab and opening the panic link.
When the tab loses focus (user switched away — likely checking if this tab is non-educational), instantly swap the title/favicon to a random educational preset (faster than the 5s cycle). If docked DevTools is detected (window.outerWidth − innerWidth > 160px) or a debugger-statement timing hit fires, immediately window.location.replace() to the panic link with no history entry.
